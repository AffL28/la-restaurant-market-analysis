# Análise de Mercado de Restaurantes em Los Angeles

Este projeto consiste numa análise exploratória de dados sobre restaurantes em Los Angeles com o objetivo de apoiar a tomada de decisão para a abertura de uma nova cafeteria com garçons robôs.

O objetivo da análise é compreender as características do mercado atual de restaurantes em Los Angeles e identificar padrões relevantes relacionados com tipos de estabelecimentos, presença de redes, capacidade de assentos e distribuição geográfica.

## Objetivos do Projeto

- Analisar a distribuição dos diferentes tipos de estabelecimentos
- Avaliar a proporção de restaurantes de rede e independentes
- Identificar características típicas das redes de restaurantes
- Analisar o número médio de assentos por tipo de estabelecimento
- Identificar as ruas com maior concentração de restaurantes
- Explorar tendências na capacidade de assentos em áreas com maior densidade de restaurantes
- Apresentar recomendações estratégicas para abertura de um novo restaurante

## Conjunto de Dados

O dataset contém informações sobre restaurantes em Los Angeles:

- object_name — nome do estabelecimento  
- chain — indica se o restaurante pertence a uma rede  
- object_type — tipo de estabelecimento  
- address — endereço  
- number — número de assentos  

## Etapas da Análise

1. Preparação e limpeza dos dados  
2. Análise exploratória de dados (EDA)  
3. Visualização de dados com gráficos  
4. Análise de padrões de mercado  
5. Recomendações estratégicas para investidores
